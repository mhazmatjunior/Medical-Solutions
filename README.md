# Medical Solutions

An enterprise healthcare, logistics, medical staffing, and fleet solutions portal engineered with React, Tailwind CSS, Lucide Icons, and Vite.

## Strategic Pillars & Verticals

1. **Logistics & Cold Chain**
   - Ocean & Sea Freight (Reefer Containers)
   - Express Air Freight & Medical Charters
   - Climate-Controlled Road Freight Fleet
   - Zero-Delay Customs Clearance & Regulatory Brokerage
   - GDP-Validated Multi-Zone Cold Warehousing (-80°C to +25°C)
   - Direct-to-Pharmacy Supply Chain & Dispensing

2. **Health Supplies & Devices**
   - ICU & Diagnostic Medical Equipments
   - Precision Medical Devices & Infusion Systems
   - Sterile Consumables & Surgical Disposables
   - Institutional Formularies & Corporate Pharmacy Contracts

3. **Manpower Solutions**
   - Healthcare Skilled: Specialist Physicians, Surgeons, ICU Nurses, Paramedics
   - Skilled Labour: Biomedical Engineers, Diagnostic Pathology Lab Techs
   - Unskilled & Operational Labour: Hospital Orderlies & Sanitization Crews
   - 5-Stage Primary-Source Credentialing & Verification Protocol

4. **Rental & Fleet Solutions**
   - Type I, II, III Advanced Life Support (ALS) & BLS Ambulances
   - Heavy Medical Equipment: Mobile CT / MRI Scanning Trailers & PSA Oxygen Plants
   - Turnkey Mobile Dental & Oral Surgery Clinics
   - Comprehensive SLA, Calibration & Replacement Guarantee

## Tech Stack & Design System

- **Framework:** React 19 + Vite
- **Routing:** React Router v7
- **Styling:** Tailwind CSS with custom clinical trust palette
- **Typography:** Plus Jakarta Sans & Inter
- **Icons:** Lucide React
- **Mobile Experience:** App-style floating action bar, touch-friendly swipeable filters, and zero iOS auto-zoom disruption

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
